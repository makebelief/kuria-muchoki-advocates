# Kuria Muchoki & Co. Advocates

Static multi-page website for Kuria Muchoki & Co. Advocates, designed around the supplied black, white and gold identity.

## Pages

- `index.html` — home page
- `about.html` — firm overview
- `practice-areas.html` — all ten practice areas
- `managing-partner.html` — Michael Muchoki profile
- `contact.html` — direct contact, email enquiry and Google Maps
- `privacy.html` — operational website privacy notice
- `404.html` — branded error page

## Preview

Serve this folder with any static server, for example `python3 -m http.server 4173`, and open `http://localhost:4173`.
